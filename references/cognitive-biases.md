# 六条认知偏差检查清单

来自唐嘉序日常积累的六条认知偏差，用于文章逻辑审查阶段。

## 1. 过度泛化陷阱

**定义**：局部正确的洞见被不加边界条件地推广为全局真理。

**检查方法**：追问"这个结论在什么条件下会失效？"

**典型信号**：
- "所有 X 都会 Y"
- "从 X 这件事我们可以看出，整个行业都..."
- 用单一样本推导总体规律
- 忽略地域/时间/行业的条件限制

**应对**：要求作者明确边界条件。如果作者没有给出，标记为逻辑缺口。

## 2. 精确-准确滑坡

**定义**：因为精确数字可能不准，就推论模糊判断也不需要。将"精确"和"准确"混为一谈。

**检查方法**：区分"这个数字可能不准"和"因此定性判断也无效"——两者是独立的。

**典型信号**：
- "数据显示 X 增长 12.3%（虽然具体数字可能有出入）"
- 用数据本身的精度问题来否定基于数据的整体结论
- 在无法获得精确数据时放弃所有定量判断

**应对**：承认精确度有限，但不放弃准确性。用区间估计替代点估计。

## 3. 类比替代论证

**定义**：用表面优美的比喻替代严格逻辑推导，而类比的前提未经验证。

**检查方法**：识别文中所有比喻和类比，追问"这个类比的两个事物在关键维度上真的相似吗？"

**典型信号**：
- "这就像..." 然后基于类比得出结论
- 用历史事件类比当前情况，忽略时代差异
- 用生物学/物理学术语包装商业论述（"进化"、"熵增"）
- 用"本质上是..."来跳过论证

**应对**：区分"帮助理解"的类比和"替代论证"的类比。只有前者可以保留。

## 4. 高手可复制性幻觉

**定义**：把顶级玩家的能力假设为普通人也具备。把"他做到了"等同于"你也可以"。

**检查方法**：追问"他做到这件事依赖什么前提条件？"

**典型信号**：
- "X 做到了 Y，说明 Y 是可行的"
- 成功故事型叙事，省略失败路径
- "只要做到这三点，你也可以..."
- 忽略幸存者偏差：只看到成功的，没看到失败的

**应对**：拆解成功的前提条件（资源、时机、能力、运气）。评估可复制性。

## 5. 放弃安全边际

**定义**：用定性感受替代定量判断。

**检查方法**：追问"在这个价格买入，预期回报是多少？"（适用于投资类文章）；或更一般地追问"即使判断正确，最坏情况是什么？"

**典型信号**：
- "长期来看是向上的" 而没有考虑短期波动承受力
- "这是一个好公司" 而没谈当前价格
- 对风险的描述全是定性词汇（"较大"、"较小"、"可控"）

**应对**：要求量化。即使毛估估的数字也比只有定性描述好。

## 6. 忽视机会成本

**定义**：持有 = 每天都在做买入决策。忽视"如果现在有一笔新资金，你还会买它吗？"

**检查方法**：追问"如果现在有一笔新资金，你会怎么配置？"

**典型信号**：
- "我已经持有了所以..."
- 对现有持仓的辩护性论述
- "可以继续持有" 但没有论证为什么比卖出换别的更好

**应对**：强制用零基思维重新评估。持仓不等于正确。
